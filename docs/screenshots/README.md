# Screenshots

The main `README.md` shows these images. They are taken from the running application by the developer (Claude's workspace cannot run the app, so it cannot make them).

| File | Screen | Suggested content |
|---|---|---|
| `dashboard.png` | Dashboard | Two workspaces, a few projects, My Tasks, and recent activity |
| `board.png` | Project Board | Tasks in all four columns, with priorities, deadlines, and a label |
| `task.png` | Task page | A task with description, checklist, notes, and labels |
| `calendar.png` | Calendar | A month with a few deadlines, one of them overdue |
| `documents.png` | Documents | The list on the left and an open document on the right |
| `backup.png` | Settings, Backup and restore | The two cards (Export and Restore) |

How to take them:

1. Use the window at its default size (1200x680) or maximized, with sample data only (no real personal data).
2. Press `Win + Shift + S`, select the window, and save as PNG.
3. Put the files in this folder with the exact names above, then `git add docs/screenshots` and commit.

Until the files exist, the images in the README show as broken links on GitHub.
